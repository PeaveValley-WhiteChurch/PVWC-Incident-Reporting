# PVWC Incident Reporting

A standalone, mobile-friendly static website for Peace Valley–White Church Fire Department.

## Privacy and data handling
- No account, database, API, analytics, or report upload is used.
- Report content and selected photos stay in the current browser page memory only.
- The app does not save reports to local storage or send them to a server.
- Use **Generate / Print PDF** to open the device/browser print dialog and choose Save as PDF or the device's PDF/share option.
- Clear the form or close the tab after generating the report, especially on shared devices.

## Deployment
Static site. Build command: `echo "Static site ready"`. Publish directory: `.`.

## Notes
The print dialog is provided by the user's browser/operating system. Exact PDF save/share steps vary by device. This is a report-preparation tool, not an official records-retention system.
